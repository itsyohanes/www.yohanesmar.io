# yohanesmar.io: static site

A static rebuild of [yohanesmar.io](https://www.yohanesmar.io/) with no WordPress and no runtime dependencies. The HTML in this repo is the finished site, ready to upload as-is.

## Structure

```
index.html                       Home
about/index.html                 About
portfolio/index.html             Portfolio grid
<case-study>/index.html          ausev, advanced-manufacturing-queensland, hydronics,
                                 ausmv, lookaroo, australian-owned
404.html                         Not-found page (picked up by Netlify, GitHub Pages, Cloudflare Pages)
sitemap.xml, robots.txt
assets/css/style.css             All styles
assets/js/main.js                Mobile menu, lightbox, homepage scroll effects
assets/fonts/                    Poppins, Roboto Condensed, Roboto Flex (self-hosted)
assets/img/                      Logos / favicon
assets/img/og/                   1200×630 social share images, one per page
assets/media/<project>/          Images (WebP/JPG) and video per page
tools/build.mjs                  Page generator (see below)
```

URLs match the old WordPress permalinks (`/about/`, `/ausev/`, …), so existing links keep working.

## Editing pages

All page HTML, `sitemap.xml` and `robots.txt` are generated by `tools/build.mjs`. That one file holds the shared header, menu and footer, the project list and each case study's content. To change any of these:

1. Edit `tools/build.mjs`.
2. From the repo root, run `node tools/build.mjs`. It needs Node 18+ and nothing else, no `npm install`.
3. Commit both the script and the regenerated HTML.

Don't hand-edit the generated `.html` files: the next build overwrites them. Styles (`assets/css/style.css`) and behaviour (`assets/js/main.js`) aren't generated, so edit those directly.

To add an image, drop it in `assets/media/<project>/` and reference it from the script. The script reads width and height from the file itself (JPG, PNG, WebP).

## Run locally

Any static server works:

```
python -m http.server 8080
```

Then open http://localhost:8080.

## Deploy

Upload the folder as-is to any static host, such as Netlify, Cloudflare Pages, GitHub Pages or plain nginx. No build step is needed on the host, because the generated HTML is committed. `tools/` is harmless to upload but can be excluded.
